# Public-domain exercise photos

From https://github.com/yuhonas/free-exercise-db — released under the
**Unlicense** (public domain). No attribution required and no restriction on
redistribution, so unlike `media/images` and `media/videos` these files ship in
the deployed build.

Two photos per exercise: `0.jpg` (start position) and `1.jpg` (end position).
The app alternates them to animate the movement.
